# 配信タスクウィジェット ジェネレーター

複数のタスクを登録・チェックできる、OBS配信用のブラウザソースです。
本ツールはWebで完結します。

## 使い方

1. [`index.html`](https://soboronin.github.io/OBS-Task-Widget/)を開く
2. タスクウィジェットの見た目をお好みで調整する
3. 表示された2つのURLをそれぞれコピーする
   - ➀配信画面用（表示専用）
   - ➁操作用（タスクの追加・チェック用）
4. ➀をコピーし、OBSで「ブラウザ」ソースを追加してURL欄に貼る（幅・高さはお好みでOK）
5. ➁をコピーし、OBSメニューの「ドック(D)」→「カスタムブラウザドック」からURLを登録する（ドック名はなんでもOK）
6. 配信中はドック（➁）側でタスクの追加・チェックを行うと、配信画面（➀）にリアルタイムで反映されます
※➀はOBSの映像として合成されるだけなので、直接クリックしても反応しません。タスクの操作は必ずドック（➁）側で行ってください。

## 機能

- 複数のタスクを登録できます
- タスクをクリックしてチェック(完了)をつけられます
- フォント・文字色・アクセント色・背景色・背景の不透明度を変更できます
- フォントはお使いのPCに入っているフォント名をそのまま指定できます（Local Font Access APIでPC内のフォント一覧を読み込むことも可能、対応ブラウザのみ）
- OBSのブラウザソースに設定した幅に応じて、文字サイズ・折り返し位置が自動調整されます
- タスクや見た目の設定はOBSを再起動しても残ります

## 注意

- 一部のフォントは配信者本人のPCに入っていれば使われます。無ければ自動でお使いのPC標準フォントに置き換わります
- Googleフォントを指定した場合、インターネット接続がある環境で正しく表示されます
- 本ツールは一部生成AIを使用して制作しています
- ブラウザやOBSのアップデートなどにより、予告なく正常に動作しなくなる場合があります
